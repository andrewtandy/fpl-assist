## What slipped

- **Prettier carried over to S01.** It's a stated convention, but there's no config and no format check in CI. Tracked as #14.
- **Board and README tickets were late, not dropped.** They were only caught when S00 was compared ticket by ticket with the plan, which wasn't in the repo until the end of the sprint. Lesson for later sprints: put the plan's ticket list in the repo before starting.
- **The budget is outside Terraform.** It was created by hand before any Terraform existed. It could be imported as `azurerm_consumption_budget_subscription` in S01 so the hard rule has no exceptions beyond the state bootstrap.

## Lesson

Check that a gate works before relying on it. Two checks here looked healthy but weren't. `npm run typecheck` had been crashing, not passing, so type errors would have slipped through. The first CI workflow's path filter would have left docs-only PRs waiting forever for a required check that never ran. A check that never runs or always crashes looks a lot like one that passes, so each new gate needs one deliberate run to prove it fails when it should.
